MapDesk - MT

Programa de acesso remoto para Windows que a MT - Manfred Tecnologia usa no suporte. O técnico vê a sua tela e resolve o problema com você, pelo servidor da MT, e a conexão só começa quando você aceita.

Baixar para Windows Ver o código

Versão 1.5.0-mt.1, para Windows 64 bits. Um arquivo só, o MapDesk-MT.exe.

O arquivo vem do GitHub. O SHA-256 para conferir o download está na página da versão.

Use só em computadores que você tem autorização para usar ou administrar. Veja o uso autorizado.

Por que ele existe

Boa parte do suporte de TI se resolve sem ir até o cliente. O técnico precisa ver a tela, mexer no mouse por alguns minutos e, às vezes, mandar um arquivo. Para isso existe o acesso remoto.

No MapDesk - MT, a conexão passa só pelo servidor da MT, que fica no Brasil. E nada acontece sem você: o técnico só entra depois que alguém na frente do computador aceita o pedido.

O que ele faz

Aceite pelo botão verde

O pedido de conexão aparece na tela. O técnico só vê o computador depois do clique em Aceitar.

Senha permanente opcional

O programa vem sem senha. Para atender sem ninguém na frente do computador, o técnico configura uma senha naquela máquina.

Transferência de arquivos

Envia e recebe arquivos durante o atendimento.

Repasse

Quando os dois computadores não conseguem se ligar direto, a conexão passa pelo servidor de repasse da MT.

Servidor travado

O programa só se liga ao servidor e à chave da MT, que já vêm dentro dele. Não dá para apontar para outro servidor.

Marca da MT

Nome, ícones e cores da MT, para você reconhecer o programa do seu suporte.

Como usar

  1. Baixe o MapDesk-MT.exe.
  2. Dê um duplo clique nele.
  3. Informe ao técnico o número de ID que aparece na janela.
  4. Quando o pedido de conexão chegar, clique no botão verde Aceitar. Para encerrar, basta fechar a conexão.

Aviso do Windows

O MapDesk-MT.exe ainda não tem assinatura digital, que é um certificado pago. Por isso o Windows desconfia dele na primeira vez.

Se aparecer "O Windows protegeu o seu computador", é o SmartScreen. Clique em Mais informações e depois em Executar assim mesmo.

O Controle Inteligente de Aplicativos (Smart App Control) é outra história: ele não oferece esse botão. Nos computadores em que ele está ligado, o programa não abre enquanto não tiver a assinatura. Se for o seu caso, avise o técnico.

Privacidade

O servidor da MT registra o número de ID de cada computador, o endereço IP e o horário de cada conexão. Esses registros ficam guardados por 6 meses, com acesso restrito. O servidor não grava a tela nem o conteúdo do atendimento.

Os detalhes estão na página de privacidade.
